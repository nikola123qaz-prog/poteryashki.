# Потеряшки — стартовый проект VK Mini Apps

Мобильный React/Vite интерфейс для двух пунктов выдачи: Советская и Титова.

## Уже есть в прототипе
- Меню: Найденные товары, Не нашли товар, Советская, Титова, Мои записи.
- Поиск и фильтр по пункту выдачи.
- Форма новой записи с датами, описанием и ссылкой на фото.
- Кнопка «Я нашёл / нашла» / «Я нашёл товар».
- Поля статусов и заготовка интеграции с Supabase.
- Инициализация VK Bridge и чтение VK ID.

## Запуск локально
1. Установить Node.js LTS.
2. Распаковать проект и в его папке выполнить:
   ```bash
   npm install
   npm run dev
   ```
3. Открыть адрес, показанный Vite.

Без настройки Supabase показываются две демонстрационные карточки. Записи в этом режиме не сохраняются после перезагрузки.

## Подключение Supabase
1. Создать проект в Supabase.
2. Выполнить `supabase/schema.sql` в SQL Editor.
3. Создать Storage bucket для фотографий.
4. Скопировать `.env.example` в `.env` и заполнить URL и anon key.
5. Перед публикацией настроить RLS и серверную проверку менеджеров.

## Важно перед публикацией
Это стартовый код, не готовый production-сервис. Переключатель «Войти как менеджер» — только демонстрация интерфейса и не является защитой доступа. Перед реальным использованием необходимо:
- убрать демо-переключатель и авторизовать менеджеров через проверку VK ID на сервере;
- настроить политики RLS для всех таблиц и Storage;
- реализовать безопасный серверный endpoint для заявок;
- настроить VK-сообщество/бота с правами отправки сообщений в существующую беседу;
- хранить токены только на сервере, не в коде фронтенда;
- проверить требования VK Mini Apps к домену, HTTPS и публикации.
